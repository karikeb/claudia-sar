# Tarjeta digital de Claudia Sar

Proyecto estático pensado principalmente para celular y listo para subir a Vercel.

## Archivos
- index.html
- styles.css
- claudia.jpg
- rotary.jpg
- claudia-sar.vcf

## Publicar en Vercel
1. Descomprimí la carpeta.
2. Subila a un repositorio de GitHub.
3. En Vercel elegí Add New > Project.
4. Seleccioná el repositorio.
5. Framework Preset: Other.
6. No hace falta Build Command.
7. No hace falta Output Directory.
8. Deploy.

## Botones
- Guardar contacto: abre la vCard.
- WhatsApp: abre el chat.
- Llamar: inicia llamada.
- Email: abre el cliente de correo.
- Instagram: abre el perfil.
- Ubicación: abre Google Maps.

## Nota
Cuando tengas la URL definitiva de Vercel, conviene actualizar las metaetiquetas Open Graph
para que al compartir por WhatsApp aparezca una vista previa más prolija.
